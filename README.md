# Аура — главная для согласования

Демоверсия: **https://nemchick.github.io/office-partner-preview/**

В этом репозитории размещена только готовая демосборка главной страницы. Это не основной репозиторий исходников сайта. Внутренние страницы, архив старого сайта, Excel, Figma, секреты и локальные настройки сюда не загружаются.

Работают адаптивная вёрстка, логотипы клиентов, карта с карточками городов, пример сервиса контроля печати, FAQ, формы и расчёт на три шага. Формы демонстрационные: данные выводятся только в консоль браузера, не сохраняются и не отправляются менеджерам. При переходе во внутренние разделы появляется сообщение, что пока доступна только главная.

Сайт работает на GitHub Pages без JSON Server и без включённого компьютера разработчика. Публичные данные подготовлены из локального db.json при сборке. Указан noindex; robots.txt запрещает обход демоверсии.

## Публикация

Файлы сайта находятся в site/. GitHub Actions публикует их после изменений в main. Источники логотипов указаны в docs/client-logo-sources.json.

Для обновления из рабочего проекта frontend:

1. npm run build:pages
2. npm run test:pages
3. npm run publish:pages

Основная версия проекта продолжает работать через SvelteKit SSR и JSON Server.
